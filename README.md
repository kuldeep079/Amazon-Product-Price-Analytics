## 📌 Project Overview

Amazon Product Price Analytics is a data analytics project that explores product prices, discounts, ratings, and potential customer savings.

The project uses Python for data cleaning, SQL Server for data analysis, and Power BI for interactive visualization.

## 🛠️ Tech Stack

- Python – Data Cleaning and Preprocessing
- SQL Server – Data Storage and SQL Analysis
- Power BI – Interactive Dashboard
- GitHub – Project Documentation

## 📊 Key Features

- Total Products and Average Rating KPIs
- Average Discount Analysis
- Actual Price vs. Discounted Price Comparison
- Product Rating Distribution
- Discount Range Distribution
- Category Performance Analysis
- Top 10 Products by Customer Savings
- Interactive Dashboard Filters

## ⚠️ Data Disclaimer

This project uses a static dataset for analytical and educational purposes. It does not track live Amazon prices.
